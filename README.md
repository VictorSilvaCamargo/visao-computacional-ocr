## 📖 Visão Geral

Soluções práticas de processamento digital de imagens: Reconhecimento Óptico de Caracteres (OCR) com Tesseract, filtragem espacial, morfologia matemática, detecção de bordas e extração de características visuais.

Este repositório reúne projetos práticos desenvolvidos com foco em engenharia de dados e inteligência artificial, demonstrando desde fundamentos teóricos até implementações práticas com validação experimental e métricas salvas.

---

## 🌟 Destaques do Portfólio

### 🔹 [Reconhecimento Óptico de Caracteres (OCR) com OpenCV e Tesseract](./01_ocr_tesseract_opencv.ipynb)
Pipeline para leitura e extração de texto em imagens reais: binarização adaptativa, remoção de ruídos e OCR via Tesseract Engine.

- **Stack:** `OpenCV` `Tesseract OCR` `Binarização` `Visão`
- **Notebook:** [`01_ocr_tesseract_opencv.ipynb`](./01_ocr_tesseract_opencv.ipynb)

### 🔹 [Filtros Espaciais, Convolução e Detecção de Bordas](./02_visao_computacional_filtros.ipynb)
Aplicação de máscaras de Sobel, Laplaciano, filtro Gaussiano e operações morfológicas (dilatação e erosão) em imagens digitais.

- **Stack:** `OpenCV` `Filtros Digitais` `Morfologia`
- **Notebook:** [`02_visao_computacional_filtros.ipynb`](./02_visao_computacional_filtros.ipynb)

### 🔹 [Extração de Características Visuais](./03_extracao_caracteristicas_visuais.ipynb)
Combinação de descritores de imagem com modelos neurais para detecção de padrões visuais e representação espacial.

- **Stack:** `OpenCV` `Keras` `Feature Extraction`
- **Notebook:** [`03_extracao_caracteristicas_visuais.ipynb`](./03_extracao_caracteristicas_visuais.ipynb)

## 🚀 Como Executar Localmente

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/VictorSilvaCamargo/visao-computacional-ocr.git
   cd visao-computacional-ocr
   ```
2. **Crie e ative um ambiente virtual:**
   ```bash
   python -m venv venv
   # Windows:
   .\venv\Scripts\activate
   # Linux/macOS:
   source venv/bin/activate
   ```
3. **Instale as dependências:**
   ```bash
   pip install -r requirements.txt
   ```
4. **Inicie o Jupyter Notebook:**
   ```bash
   jupyter notebook
   ```
